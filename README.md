# E-Commerce-Sales-Analysis

This assignment focuses on E-Commerce Sales Analysis using Microsoft Power BI. It involves importing, cleaning, and transforming sales data using Power Query Editor. Various data transformation techniques, such as changing data types, merging tables, handling missing values and duplicates, sorting, filtering, and grouping, are performed. Data modeling is also carried out by establishing relationships between tables. This assignment helps develop practical skills in data preparation, data organization, and analysis using Power BI.
